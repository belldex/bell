Formulas

fee = max(baseFee, proposal_1 ... proposal_n) x (100 - max rebate_i) / 100
royalty_i = |unspecified amount| x royaltyBps_i / 10,000, with sum(royaltyBps_i) <= 30
author_i = royalty_i x 0.8, vesting 7 days reserve += royalty_i - author_i
a hook may run only if gasleft >= gasLimit x 64 / 63 + 30,000, else the swap reverts
repay per unit (Q128) += seized x 2^128 / total LP units of the pool
