Pons coins and v4 Marketplace pools

A Pons pool is bound to the Pons hook for good, so a Pons coin gets a v4 Marketplace pool beside it.

A pool beside the Pons pool

The Pons hook carries beforeInitialize, afterSwap and afterSwapReturnDelta, and every graduated Pons pool keeps it. A coin's v4 Marketplace pool uses the same pair and opens at the Pons pool's price, read from the PoolManager. In the app, paste the coin in Create a pool. Anti-snipe and the volatility fee are the default stack.

The keeper

Every hour the house keeper compares each house pool with its reference pool (the Uniswap v3 stock pool, or the Pons pool for a coin). When the gap is over 0.3%, it swaps the pool back toward the reference price with a price limit, from its own small inventory.

House pools

TSLA, NVDA and QQQ against USDG, each stacked with the four house hooks and seeded with about a dollar of house liquidity. House actors also swap a few cents through each one every hour, so royalties, failed runs and Live swaps move from day one.
