# Token logo sources

The app uses token marks from Veil's `public/tokens` assets where they already exist: AAPL, MSFT, NVDA, PONS, SPY and TSLA. These render in equal-sized circular badges, preserving each source logo's proportions and colors. WETH/ETH uses the token mark for the canonical WETH contract from [Trust Wallet's token assets](https://github.com/trustwallet/assets/blob/master/blockchains/ethereum/tokenlist.json), rather than a wide Ethereum wordmark squeezed into a token slot.

Additional marks added for symbols missing from Veil:

- USDG: [official 512×512 USDG token logo hosted by Global Dollar](https://globaldollar.com/brand)
- AMZN: [Amazon icon.svg on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Amazon_icon.svg)
- PLTR: [Palantir SVG in Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/palantir.svg)

Simple Icons' project license does not automatically apply to every icon; its disclaimer says to check the per-icon license and applicable brand guidelines. The UI renders these as grayscale ticker marks.
